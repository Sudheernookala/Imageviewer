# Image Viewer — Angular app

This folder is the web app that GitHub Pages hosts.

Setup, deployment and usage are documented in the main [README](../README.md). The app shows the same README as its in-app **Guide**, so there is only one copy to keep up to date.

Quick start:

```bash
npm install
npm start          # http://localhost:4200
npm run build      # output: dist/image-viewer-ui/browser
```
